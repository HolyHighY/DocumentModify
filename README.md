# DocumentModify：辅助文档写作规范

本仓库用于组织人和 AI 协作编写报告的流程。支持外网准备公开资料、内网结合实际材料写作，以及依据 Word/WPS 模板交付文档。适用范围包括实验报告、调研报告和技术方案。

## 从哪里开始

| 类别 | 文件 | 用途 |
| --- | --- | --- |
| 通用写作规范 | [01-common.md](docs/01-common.md) | 事实、证据、引用、模板、图表和交付标准 |
| 外网操作规范 | [02-external.md](docs/02-external.md) | 公开研究、通用内容准备和离线写作包 |
| 内网操作规范 | [03-internal.md](docs/03-internal.md) | 先验证本机能力，再确定材料接入、分章写作、Python/WPS 读写和排版方法 |
| 报告类型补充规则 | [04-report-types.md](docs/04-report-types.md) | 实验报告、调研报告和技术方案的附加要求 |
| 可复用表单 | [05-templates.md](docs/05-templates.md) | 任务单、模板约定、材料清单、交接说明和验收清单等 |

AI 接到写作任务后，先读通用规范、对应网络环境的操作规范、对应报告类型规则，再用表单建立任务记录。**内网首次使用、机器或 WPS/加密策略改变时，必须先执行内网资格验证；不能直接声称已有读写方法可用。**

仓库本身不存放真实实验数据、内网文档、密钥或受限材料。每份报告建立独立的工作目录；内网产生的内容默认留在内网。外网至内网的交接无需依赖任何反向传输。

## 辅助检查工具

[tools/document_check.py](tools/document_check.py) 仅依赖 Python 3 标准库，提供环境探测、文件完整性清单和普通 DOCX 结构检查。它不解密文档、不控制 WPS，也不判断最终版面是否正确。具体命令与判定规则见操作规范。

## 当前边界

这些文件定义工作方法，不代表已在某台内网机器验证通过。内网的可用读写路线、离线依赖、WPS 接口和排版检查结果，必须在该机器执行后写入项目的资格验证记录。
