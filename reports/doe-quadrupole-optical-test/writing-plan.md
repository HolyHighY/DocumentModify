## 一、实验目的与技术路线

计划说明：

- DOE在投影光刻照明系统中实现四极光瞳整形的应用背景，以及本次单器件测试的目的。
- GS设计、标量衍射传播与傅里叶透镜焦面测量之间的关系，交代模型适用条件。
- 评价内容：四极光瞳形貌、六项光瞳特性参数，以及目标光瞳的衍射效率。
- 技术路线：设计目标与坐标确认 → 光路搭建及标定 → CMOS图像采集 → 有／无DOE功率测量 → 参数计算 → 结果分析。

明确测试面与系统照明光瞳的映射条件，不由单器件结果直接推断晶圆成像或工艺收益。

## 二、实验设计与方案

按“测试对象与条件—装置—采集—处理”的顺序组织。

| 拟设内容 | 撰写重点 |
| --- | --- |
| 样品与设计目标 | 样品标识、设计版本、四极目标形貌、方向基准；未知条件留待内网填写 |
| 测试设备与条件 | 波长、偏振、入射束径、透镜、CMOS、功率计及校准信息 |
| 光瞳场测量 | 光源—DOE—傅里叶透镜—CMOS；焦面确认、尺度与方向标定、曝光和背景采集 |
| 衍射效率测量 | 光源—DOE—傅里叶透镜—功率计；有／无DOE参考配置、背景和漂移控制 |
| 参数处理 | 八分区编号、净能量积分、六项指标公式、目标区域与共同收集域 |
| 误差与重复性 | 饱和、截光、背景、定位、响应及功率参考等因素 |

六项参数沿用：HV椭圆度、ST椭圆度、X极平衡、Y极平衡、0°四象限极平衡、45°四象限极平衡。**前一方案中的归一化公式仍是候选定义，正式报告应与内网实际计算程序一致**，不能直接当作已确认标准。

衍射效率需明确分母及损耗边界，相机灰度只用于经验证的相对能量比例。四极张角、方位角可作为补充评价项，在确认本次测量范围后纳入。

| 拟设小节 | 需要展示的证据 | 分析重点 |

| 综合分析 | 实测与设计目标或可信仿真的比较 | 达成情况、差异及有证据支持的解释 |

如无设计预测或仿真输入，就进行实测特征与内部一致性分析，不编造理论对比值。有目标和公差时再判断是否满足要求；没有判据时只报告性能。

加工、装调或模型误差可以列为候选原因，但不能仅凭光场图认定某一种原因已经成立。
