# 公开资料归档

`reports/<项目ID>/` 保存允许公开并进入版本控制的研究稿、复核说明及冻结资料包；内网工作材料仍放在 `.local/projects/<项目ID>/`。两者可使用同一项目 ID，但不自动同步，也不互为完整备份。当前实例：[193 nm DOE 材料替换调研](193nm-doe-quartz-survey/README.md)。

新归档优先采用以下结构；按需创建，不为已有归档强制改名或复制重复文件：

```text
reports/<项目ID>/
  README.md                 # 入口、范围、版本、文件索引和内网下一步
  report-v0.1.md            # 公开研究稿，标明草稿及证据边界
  review.md                 # 实际复核范围、未解决项及版本变化
  assets/                   # 正文实际引用且允许公开的图片
  <项目ID>-research-v1.zip   # 可选，已核验的冻结离线包
```

归档入口写明报告目的、资料截止日期、稿件/包版本、来源与离线证据位置、模板状态、已通过与未执行的检查，以及包解压后的 `ENTRY.md` 和 `MANIFEST.json` 路径。正文中的图片路径相对于正文文件；包内资源应使用包内相对路径，单独解压仍能阅读。

提交前逐项核对公开范围、转载许可、引用与图片路径，检查 ZIP 内全部成员，确认不含 `.local/`、内网模板、内部材料、凭据或不允许发布的原始文献。只从已审核文件构建归档，不整包复制本地项目。外网资料包的生成和解压复核按 [外网规范](../docs/02-external.md#5-打包与交接验证) 执行；冻结包不原地修改，更新时新增版本并更新入口。已有历史包保留原版本规范，不冒充本轮重新验证。

内网接收后先按当前仓库规范核验包，再读取真实模板，按 [有／无额外资料流程](../docs/03-internal.md#101-有无额外资料的完整写作流程) 写作。公开归档稿不代表内网报告或 Word 已定稿；内网生成内容不回传到本目录。
