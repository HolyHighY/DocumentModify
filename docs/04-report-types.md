# 04 报告类型补充规则

与 [通用规范](01-common.md) 同时使用。用户模板决定实际章节名与顺序，以下是内容覆盖要求，不是强制替换模板的目录。

## 1. 实验报告

### 必要输入

- 测试目的、被测对象和样品标识；哪些指标属于目标值，哪些是实测值。
- 真实测试条件、设备与配置、过程记录、原始数据及单位。
- 实际照片和需要的装置/光路示意图；区分实际搭建与原理示意。
- 适用的标准、比较基准、数据处理方法，以及已知不确定因素。

先列缺口及影响。温度、校准状态、重复次数等未提供时不默认补造；不相关或确实未记录时如实说明。

### 内容与分析

覆盖背景、理论、方法、结果、讨论、结论和局限。描述实际步骤时依据记录，不能用理论上应当发生的步骤替代。

保留原始数据，记录清洗、异常点、拟合、换算和统计方法。剔除数据必须有理由及记录；不可为使结果符合预期而选择性处理。误差条要说明代表标准差、标准误、置信区间还是其他量。

例如光学器件性能测试：插入损耗、消光比、带宽、响应度等定义及计算方式必须与实际测试相符；光源波长、输入功率、偏振、基准测量和仪器范围仅在实际已知时填写。不能将不同条件的数据直接比较，也不能把仪器极限误认为器件性能。

光路图核对光源、调制/偏振器件、被测器件、探测器、连接方向和端口。不能因示意图画出了某器件，就把它加入真实实验过程。

### 交付前专项检查

- 图表能回溯原始数据及处理步骤，数量级和单位正确。
- “达到某指标”的判定有条件、基准和证据；缺少不确定度评估时如实披露。
- 区分结果、原因推测和建议的后续实验。
- 所有合成示例已排除出正式结果。

## 2. 调研报告

### 必要输入

问题、决策用途、读者、地域/行业/技术范围、资料截止日期、期望覆盖深度、已有来源和限制。

### 内容与分析

记录检索范围、渠道、关键词、纳入与排除条件。无法联网或覆盖有限时，写清资料范围，不能声称完成全面检索。

优先一手来源，区分同行评议研究、标准、官方数据、厂商材料和个人观点。市场规模、性能比较、政策结论等需核对口径、时间、样本、单位和利益关系。

比较表中的每项指标保留来源和条件；未公开写“未找到”，不能补推测数值。相互冲突的观点说明证据和适用范围。预测、估计与已发生事实分开。

建议部分说明评价标准、证据、权衡和不确定性，避免从少数材料推出全行业结论。

### 交付前专项检查

- 日期、版本和范围明确，重要来源可离线追溯。
- 比较采用相同口径或明确注明差异。
- 待核实信息不承担关键结论。
- 综述与建议回应最初问题，而非仅罗列资料。

## 3. 技术方案及其他报告

技术方案补充：需求及验收条件、现状、约束、候选方案、取舍、实施步骤、资源、风险和验证计划。未做的实验或验证只能写成计划，不能写成已证明的可行性。

其他报告先确定：核心问题、证据类型、分析方法、输出对象、验收条件。沿用通用流程，按需增加专项检查，不必强行套用实验报告结构。
