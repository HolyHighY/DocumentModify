# 05 可复用表单

复制需要的表单到 `.local/projects/<项目ID>/` 或 `.local/environments/<环境ID>/` 填写，不提交真实材料或内网记录。未知字段填“待确认”，不填猜测值。一个文件可以包含多张表单，小任务无需拆出大量空文件。目录和简明流程见 [START.md](../START.md)。

```markdown
- 已有材料 ID：
- 允许 AI 完成的部分：

- 任务状态 / 更新日期：
```

## 模板约定

取得真实模板后填写；外网看不到模板时只登记待内网解析，不填写推测的模板要求。

两种交付模式均填写模板内容要求。md-only 将 Word 样式与页面要求记录为用户转换后落实的事项；只读提取或用户内网核对摘录须注明实际检查范围，读取不到的信息仍为待确认。

```markdown
# TEMPLATE-CONTRACT
- 模板文件 ID / 版本 / 摘要：
- 已实际检查的工具与范围：
- 交付模式及模板要求的责任分工：
- 首页必填字段及来源：
- 必须保留的章节名称与顺序：
- 可增加的标题级别及编号方式：
- 正文、标题、图题、表题和参考文献样式：
- 表格、公式与图片布局：
- 页面、页眉页脚、页码和目录要求：
- 缺少内容或不适用章节的处理：
- 禁止修改的部分：
- 模板未规定时采用的默认值：
- 需要用户确认的事项：
- 已确认决定及日期：
```

## 报告验收与交付记录

每项填写状态、证据和检查人；不能把未勾选解释为不适用。

两种模式都执行内容类检查。md-only 不以 Word 写入、转换或版面验收作为 AI 交付门槛；相关 AI 操作记为 `N/A（模式范围外）`，用户转换和排版工作另记 `NOT_RUN`。图片使用本地相对路径，来源引用与参考文献纳入正文；原始数据、分析源和核对记录在项目内留存，不默认成为额外交付附件。

| 检查项 | 状态 | 证据/问题与责任 |
| --- | --- | --- |
| 原始数据、单位、条件和计算核对 | 待检查 | 待填 |
| 理论、论断与引用可追溯 | 待检查 | 待填 |
| 真实照片、数据图、示意图性质明确 | 待检查 | 待填 |
| 全文章节、术语和结论一致 | 待检查 | 待填 |
| 首页必填信息、章节名称/顺序/层级符合模板 | 待检查 | 待填 |
| 正文表格、公式表达、图题、图片及来源/交叉引用完整 | 待检查 | 待填 |
| md-only：Markdown 保存重读、必要图片文件与相对路径对应 | 待检查；word 为 N/A | 待填 |
| word：模板样式、目录和页码符合要求 | 待检查；md-only 的 AI 操作为 N/A | 待填 |
| word：保存后在目标应用重新打开 | 待检查；md-only 的 AI 操作为 N/A | 待填 |
| word：字体、分页、页眉页脚、页码和图表逐页核对 | 待检查；md-only 的 AI 操作为 N/A | 待填 |
| 合成样例、待补标记和修订内容处理得当 | 待检查 | 待填 |
| 文件范围、版本及交付格式符合要求 | 待检查 | 待填 |

```markdown
- 交付版本与文件清单：
- 交付模式：word / md-only。
- 允许交付的范围与接收位置：
- 内容状态：草稿 / 待复核 / Markdown 内容已检查（md-only）/ 已验收（word，须含实际版面验收证据）。
- 已通过的检查及证据：

- Word 转换及排版待用户完成（md-only 必填）：责任为用户；用已有内网应用手动转换、应用模板样式、保存重开，检查目录/页码/表格/公式/图片和逐页版面；初始状态 NOT_RUN，实际完成后记录用户确认与证据。
- 未解决问题、局限和需要用户完成的动作：
```

md-only 内容检查通过可以交付 Markdown 正文及必要图片资源，不要求先完成用户的 Word 工作；不得将“Markdown 内容已检查”表述为 Word 已定稿或已验收。
