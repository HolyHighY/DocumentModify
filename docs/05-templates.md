# 05 可复用表单

复制需要的表单到 `.local/projects/<项目ID>/` 或 `.local/environments/<环境ID>/` 填写，不提交真实材料或内网记录。未知字段填“待确认”，不填猜测值。一个文件可以包含多张表单，小任务无需拆出大量空文件。目录和简明流程见 [START.md](../START.md)。

## 任务单

```markdown
# TASK
- 报告 ID / 名称：

- 读者与使用场景：
- 类型 / 适用补充规则：
- 工作环境与允许资料范围：
- 输出格式、语言、篇幅与时间要求：
- 模板 ID / 版本：
- 模板可用状态：已取得 / 仅内网可见、待解析。
- 本机环境 ID / LOCAL-WORKFLOW 版本 / 证据 ID：
- 已有材料 ID：
- 允许 AI 完成的部分：
- 必须依据实际材料的部分：
- 缺失信息与关键阻塞：
- 默认假设及其影响：
- 完成与验收条件：
- 任务状态 / 更新日期：
```

## 模板约定

取得真实模板后填写；外网看不到模板时只登记待内网解析，不填写推测的模板要求。

```markdown
# TEMPLATE-CONTRACT
- 模板文件 ID / 版本 / 摘要：
- 已实际检查的工具与范围：
- 首页必填字段及来源：
- 必须保留的章节名称与顺序：
- 可增加的标题级别及编号方式：
- 正文、标题、图题、表题和参考文献样式：
- 表格、公式与图片布局：
- 页面、页眉页脚、页码和目录要求：
- 缺少内容或不适用章节的处理：
- 禁止修改的部分：
- 模板未规定时采用的默认值：
- 需要用户确认的事项：
- 已确认决定及日期：
```

## 交接入口与恢复说明

```markdown
# ENTRY：下一位 AI 从这里开始

- 阅读顺序：任务单 → 模块索引/模板约定 → 暂定结构/最终大纲 → 术语/决策 → 当前材料。
```
